# MorphoLab 0.1.0 · Research prototype

首个可运行科研版本，面向果蝇胚胎in vivo激光创面的历史注释条件形态预测。
源码、真实研究报告、原始提交轨迹、工作台与独立权重包共同构成交付；不是临床工具或未来显微纹理生成器。

## 范围

- 62条/7,229帧实际公开数据审计，64网格7,183有效帧，完整时间索引与独立45/12/5协议。
- 两个经典方法、ConvGRU、NCA、更新正则与H1监督消融；4配置×3seeds×600步。
- 真实test5个源序列代理、25共同窗口；NCA H24 IoU0.4596±0.0269，边界指标未全面领先；正则收益很小，提前闭合失败保留。
- CPU工作台：真实图层、坐标与前帧参照、持久预测/取消/历史、独立PNG误差层、曲线、来源/配置/失败案例。
- Pydantic/OpenAPI生成契约、依赖锁、双平台CI、真实E2E、CPU复算和完整复训证据。
