# 局限与尚未取得的证据

- **少量代理组。** test仅5条源序列；同动物或批次关系未知。序列分组降低直接时序泄漏，但没有证明完全生物独立。窗口重叠，seed不增加生物样本数。
- **独立协议。** 原发布页61条与压缩包62条不同；官方44/12/5映射无法取得。本项目45/12/5不能冒称论文复现。
- **派生目标。** 原标签是薄轮廓；区域与SDF由严格闭曲线填充、降采样与QC派生。7,229帧中46帧在64网格无效，窗口必须完整有效。QC选择可能偏向形态规整、易标注的阶段。
- **输入依赖注释。** 当前模型需要历史形态注释，不从原始图像自动分割。原图是对齐观察与结果解释的背景，未来灰度不是生成结果。
- **尺度与时间未知。** 真实逐帧时间和物理标尺为null，指标为64网格pixel或pixel²，不能转换为微米/分钟或闭合时间。
- **预算有限。** 每配置3seeds×600步，无超参数搜索；ConvGRU参数量略多，H1实际算力更少。比较支持本协议下现象，不能证明架构总体优劣或最优性能。
- **多个指标不一致。** NCA的H24 IoU较高，但平均边界距离未胜Persistence；空预测会触发90.509668工作网格pixel惩罚。正则变化很小，不支持强改进结论。
- **不确定性不足。** seed样本SD不覆盖生物异质性、标签误差或域偏移；未作校准、置信区间、显著性或临床可靠性评价。
- **既有工作重叠。** 同数据视频预测和NCA伤口建模已有相关工作；本项目的可复算实现与对照不自动等于新颖研究贡献。
- **域迁移未评估。** 没有把GigaDB体外划痕或BBBC019静态图像拼接为本域视频，未报告跨域成功。
- **无干预因果。** 训练数据没有受控药物、基因或物理场干预。改变模型状态只能说明数值响应，不能解释为真实治疗或细胞机制。

负结果与失败案例属于正式结果，不因界面或发布需求删除。后续研究应增加有实验身份与尺度信息的独立数据、标签审核及预注册重复实验，而不是反复在当前test上选参数。
