## 网页与元数据证据

主源为 [Zenodo 7660424](https://zenodo.org/records/7660424)，[官方 API](https://zenodo.org/api/records/7660424) 已实际返回 HTTP 200、`access_right: open` 和 `license.id: cc-by-4.0`。元数据列出 `Dataset.zip`、198,715,081 bytes、`md5:5d1506d67b4be24de0304b58d17361cb`。

发布者描述：61 条果蝇胚胎 **in vivo** 激光创面闭合时序，44/12/5 train/validation/test，约每分钟一次，处理后的图像为 128×128；Video 与 Segmentations 两个目录，后者为 skeletonized segmentations。上述数量、尺寸、时间与目录是来源陈述，当前尚未由本地包内容全部核实。

采集、最大投影、配准、裁剪和降采样会改变物理标尺的解释。原文报告的原始标尺不能直接填入处理后样本；当前 `pixel_size_um: null`。生物干预条件、绝对实验时间、实验独立性和发布划分映射待确认。

## 逐帧内容核验与人工 QA

```sh
uv run --locked python scripts/audit_data.py
```

已安全读取全部62对TIFF、7,229个时间点，均为128×128；原图uint16，注释uint8。57条WH/WHu注释为0/255，5条Test注释为0/1，使用非零归一化保留原始编码。所有影像TIFF轴声明为CYX，注释为QYX或ZYX；基于发布者的video描述显式采用stack-as-time，而非把它们误当多通道或三维组织。

时间连续性仅指原始slice索引连续、未重排/跳过且影像逐帧不同；文件没有可靠的逐帧物理时间戳，不能据此证明采集时无漏帧。发布者报告60秒间隔，物理时间及处理后标尺仍为null。

| 内容检查 | 实测 |
|---|---|
| 每序列时间点 | 32–222 |
| 影像精确重复 | 跨序列0，序列内0；不等于排除近重复或证明生物独立 |
| 非零归一化注释重复 | 跨序列0，序列内23；不据此误判实验泄漏 |
| 空注释 | 0 |
| 单闭曲线候选 | 7,210/7,229 |
| 注释触边 | 26帧 |
| 单闭曲线且不触边 | 7,184帧，其余45帧须按预先定义QC处理 |

闭曲线候选定义：8邻域前景为单组件、无端点/分支像素，4连通背景恰有一个被封闭的洞；`binary_fill_holes`面积仅为派生QC量。19个非严格闭曲线帧的序列及索引保存在本地逐帧清单中，没有为了凑61条而删除序列。

本地 `artifacts/audit/annotation-contact-sheet.png` 显示WH01与WHu01各源索引0–5的原图及原始注释叠加；主代理已实际查看，橙线沿可见创面边缘，支持伤口轮廓解释，而非完整细胞junction网络。该人工判断仅覆盖这12帧，全量结构统计不能替代所有帧人工分割验证。

`artifacts/sample/` 保留两条序列各六个连续时间点的uint16 PNG和原编码注释，保存源ID、原始像素hash及PNG编码文件hash；导出后已逐像素回读核对。公开的[审计摘要](../../datasets/audits/zenodo-7660424-summary.json)只含来源、hash与QC元数据，未包含影像像素。

标签判定为**经骨架化的创面边界**，不是原始填充区域真值。后续若从可靠闭轮廓生成区域，必须标为derived annotation、定义失败规则并记录排除，不能直接把原薄线当作区域计算Dice/IoU。

## 官方划分与数量差异

作者论文与API都只提供61和44/12/5的数量，没有文件级表。[原项目页](https://lenkaback.github.io/wound-healing-modeling/)及候选公开GitHub仓库本次返回404；作者公开仓库和有限镜像检索未找到split或被排除的文件ID。查到的BiaPy分割模板为占位路径，不能用于还原预测实验划分。

因此每条 `official_split` 仍未知；Test01–05只保留名称提示，不能声称已经复原作者测试集。如果建立MorphoLab自己的协议，必须独立命名、冻结并公开依据；禁止改称原始44/12/5或随意删一条凑数。
