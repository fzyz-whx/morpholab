# 3–5分钟现场讲解路线

本路线使用真实软件与已训练权重，不在现场启动训练。没有必须播放的视频或预设动画。
先按README准备数据、权重、构建前端并启动服务，确认health三项状态。缺资源时直接说明，不切换假数据演示。

## 0:00–0:45 · 研究问题与来源

打开Overview，说明对象是果蝇胚胎in vivo激光创面，不是体外划痕。模型需要历史轮廓，当前不生成未来显微纹理。
进入Archive，显示真实62条序列、项目split及官方split未知。解释原标签为薄线，派生区域有严格QC。

## 0:45–1:30 · 原始数据与质量

打开WH01，切换OBSERVED / ANNOTATION / overlay，逐帧或播放。
展示来源、许可、原始帧索引和未知物理时间。可打开WHu07末帧158，说明失败帧仍可见而非被删除，训练窗口会排除它。

## 1:30–2:45 · 真预测与追溯

回到WH01起点0，打开预测实验，选择NCA，L4、H24，提交一次。
解释202只是入队，独立worker完成后才有结果；不承诺固定等待时间。
结果跳到F4：灰度是实际OBSERVED原帧，虚线才是预测。打开FP/FN误差层，查看当前lead指标和面积/边界曲线。
展开溯源，指出seed按validation选、权重和数据都有hash。刷新后从实验历史恢复，显示任务没有只存在浏览器内存。

## 2:45–4:00 · 对照与负结果

进入Research，选择IoU及平均边界距离。指出5条源序列代理、3seeds、25共同窗口；SD不是生物置信区间。
NCA远期IoU高，但边界距离未全面胜Persistence；正则收益很小。讲解test最差案例中提前闭合的空预测。
可以比较H1消融，但说明同600步不等于同实际算力。

## 4:00–4:30 · 工程与边界

用原创架构图解释局部感知→共享规则→自由rollout，以及API→SQLite队列→独立worker→结果。
指出代码、模型、数据和实验都能追溯，且原始影像不进Git。源码MIT、数据与权重另有署名许可。
本版没有未经数据验证的生物干预画笔，不把模型变化称为治疗效果。

## 真实项目介绍（简历/答辩素材）

开发MorphoLab本地科研工作台，研究果蝇胚胎真实创面时序中的历史轮廓条件形态预测。实际审计62条、7,229帧公开数据，建立严格QC、派生SDF与独立实验级协议；自主实现14,622参数NCA、18,417参数ConvGRU和经典几何基线，完成4配置×3seeds训练与保留测试。NCA H24 IoU为0.4596±0.0269，但边界指标未全面领先且正则收益很小，完整保留反例。以FastAPI、SQLAlchemy/SQLite、独立CPU worker与React/TypeScript实现可追溯预测、误差层、曲线及持久历史，提供锁定依赖、双平台CI、真实E2E和独立权重包。
