# 视觉语言 · M1

状态：设计规范已定义；实际浏览器视觉与 E2E 验收由主代理执行，不能以本文代替截图。

## 信息架构与关键区域

以科学画布为中心，采用安静的深色科研仪器语言。全站顶部保留产品身份和四个内容入口；小号等宽索引用于来源、帧号和技术状态，正文用系统中文字体。避免营销横幅、指标卡墙、装饰性渐变与阴影。

三个关键区域：

1. Archive：页眉说明生物域和获取状态，横向来源条呈现 DOI/许可，下一层为可检索、按本项目划分筛选的序列表。序列整行可进入工作台；候选数据没有本地文件时如实显示“尚未获取”。
2. Studio：左栏是序列与图层，中心是最大化真实影像画布、图像状态和时间轴，右栏为当前帧 QC、来源与模型状态。工具围绕画布边缘放置，不遮挡原图。观察/原注释/叠加均取真实 PNG；原始网格为128×128，放大保持像素清晰。
3. Provenance：在画布旁持续可见源序列、本项目 split、官方 split 未知、许可；逐帧时间未核实则只使用 frame，不生成分钟或物理标尺。缺权重或运行时是信息状态；就绪预测按钮必须连接真实作业。

Overview 使用可运行数据入口和真实图像预览，简述当前阶段；Research/Methods展示冻结协议和实际报告，缺报告明确pending，不生成合成指标。

## 交互与科学标识

所有操作支持明显键盘 focus，原生按钮/select/range 提供 aria label。加载、失败、空列表各有明确文本和可执行恢复入口。播放为用户主动触发，按序列结束停止；更换序列时重置播放、帧号与影像状态。时间轴支持方向键与 Home、End；画布内空格播放，避免劫持表单输入。

OBSERVED 是灰度实测图；ANNOTATION 是原始薄轮廓，不称填充真值；叠加以亮色线和图例区分。QC失败保持可浏览并警示，不自动修补或隐藏。后续 PREDICTION 需虚线+金色+文字，IN_SILICO 需独立醒目标注，M1不呈现这些图层。

桌面以1440×900为主要目标，1280×720保持三栏；窄屏侧栏变纵向，画布仍可读。尊重 reduced-motion；无自动播放、无装饰动画。视觉验收应记录真实页面、尺寸、遮挡/溢出与操作结果。
