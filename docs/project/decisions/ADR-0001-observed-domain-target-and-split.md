# ADR-0001 · 主数据域、派生形态目标与独立划分协议

- 日期：2026-10-21
- 状态：接受；依据总任务书授权的数据审计与初始研究设计范围执行。未声称负责人已经验收科研结论。
- 适用阶段：M0 → M2；正式训练前还需冻结模型/预算协议。

## 背景与证据

[数据审计](../../research/data-audit.md)实际解析Zenodo 7660424的62对TIFF、7229帧，原图128×128 uint16，注释为骨架化薄创面轮廓。7210帧满足单闭曲线候选，26帧触边；两条件同时满足共7184帧。主代理检查了两条各六时间点叠加图，观察到注释沿创面边缘。

网页与论文称61条及44/12/5，但文件级映射和排除ID无法取得，原项目页404。没有证据证明哪个额外文件应删除；也没有可靠实验动物/采集批次ID。官方split保持未知。API许可为CC BY 4.0，无包内冲突附件，署名见数据目录。

## 备选

1. 将所有薄线直接作为区域GT计算IoU：语义错误，排除。
2. 直接预测边界点/无符号距离：合理备选，但区域闭合和内外几何较难表示。
3. 从可靠闭轮廓生成明确标记的派生区域与有符号距离场：采用，保留原注释与QC。
4. 凑成61条并猜44/12/5：无证据，排除。
5. 等待原映射而停止所有研究：保留未来对照机会，但不把失效链接作为无限期依赖。

## 选择

### 科学对象与目标

维持果蝇胚胎 **in vivo 激光创面闭合**，不转成体外划痕。任务是**观测轮廓条件下的形态预测**：输入只使用合法历史轮廓/派生形态，预测未来形态；真实显微原图用于数据浏览和对齐QA。此阶段不声称由原始灰度图自动分割、不生成未来显微纹理，也不能直接与Backová整帧视频预测分数比较。

原始边界 `B = annotation != 0`。仅接受单组件、无端点/分支、恰好一个被封闭洞且不触图边的帧；派生区域 `R = binary_fill_holes(B)`。保留原始B与编码，不补断线、不删分支、不把失败帧伪装成修复真值。QC失败保留在浏览器并明确标识，所有输入/目标跨度包含失败帧的训练或评估窗口均排除，不能压缩时间轴。

区域在128×128生成后，以最近邻降至共同64×64计算网格；若区域消失/全满也拒绝该帧。有符号欧氏距离以内部为正、外部为负，裁剪在固定±8个工作网格像素后除8；配置和版本固定。所有基线/网络使用同样输入、目标和网格。预测区域由距离场正值获得。IoU/Dice只描述**派生区域一致性**，不是与原始人工填充mask比较。

### 独立协议 `morpholab-split-v1`

保留全部62条。`Test01`–`Test05`因为发布名称已暗示测试用途，保守保留在本项目holdout，不挪入训练；这**不证明它们就是原作者的官方测试集**。

其余57条按 `sha256('morpholab-split-v1:' + sequence_id)` 排序，前12条validation，余45条train。生成冻结文件清单、hash与依据；不根据轮廓、长度或模型表现挑序列。原始官方split字段全部为null，另存本项目split。以后若取得官方映射，新增数据协议版本与单独对照，不改写当前结果。

独立单元以源序列代理，不冒称已知生物独立实验。精确重复影像未检出；继续做跨序列近重复筛查，疑似共享实验来源时先报告/分组处理再训练。每帧及裁剪继承整序列split。

### 初始评价

固定观测L=4帧，短/中/长期H=4/12/24帧；后续L=2/8作为敏感性检查，不为各模型私调输入。仅使用完整连续且全QC合格的窗口，同一比较的模型使用相同窗口集合。窗口数量、排除数和每序列结果必须报告，不能把每帧当独立实验。

主要几何指标：派生区域IoU/Dice、对称平均边界距离、Hausdorff95和面积MAE；明确单位为64×64工作网格pixel/pixel²。原始物理标尺与逐帧时间未知；发布者报告一分钟采样单独显示，不能转换成已核实µm或分钟。

## 后果与限制

- 数据审计M0可通过；61/62不一致、原划分未知和生物独立性未知作为公开限制继续保留，不隐藏。
- 目标为派生形态，研究结论仅覆盖该任务和新协议；不主张自动显微视频预测或原论文复现。
- 已知少量坏标签不丢弃整条序列，也不静默修补，窗口排除可能改变有效样本数，须披露。
- 后续正式实验仍须固定训练预算、多seed、验证选模和失败标准；NCA不如经典基线也如实报告。
