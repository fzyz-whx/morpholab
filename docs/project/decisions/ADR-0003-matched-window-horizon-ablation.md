# ADR-0003 · 多步监督消融的共同采样窗口

- 日期：2026-10-21
- 状态：接受；所有真实神经训练与test评价之前注册。

## 背景

ADR-0002的H12训练可与仅H1监督比较，回答多步监督是否改善长期预测。直接把训练跨度改成H1，会同时增加候选窗口并改变同seed采样到的历史，从而混淆监督损失与数据选择。

## 决定

把`sampling_horizon`与`train_horizon`分开。基础方案均为sampling=12、supervision=12；H1 NCA消融为sampling=12、supervision=1，其余初始化、数据、增强、Adam、batch8、600优化步和H24验证选模均相同。相同seed具有相同源序列、起点和历史输入，未来只取所需监督前缀，不改变候选池或压缩时间。

独立配置`forecast-h1-ablation.yaml`协议名`morpholab-forecast-h1-v1`；只运行NCA，seeds同为17/29/43。相比ADR-0002原先有限单seed设想，现为3seeds，以增强可比较性。它是单独登记的消融，不修改test来选择配置。

优化步数相同不代表FLOPs或墙钟时间相等：H1每步计算较少，实际成本必须报告。该对照检验在此预算规则下的多步监督，不宣称严格等计算量的因果效应。

## 验证

合成机制测试检查候选起点、历史输入及共同未来前缀逐tensor相同；采样跨度短于监督跨度直接拒绝。主协议没有改变数据域、派生目标、分组或模型结构。正式训练仍在提交、立即push和远端核对后启动。
