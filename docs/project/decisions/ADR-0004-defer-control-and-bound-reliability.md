# ADR-0004 · 本版不开放虚拟控制，可靠性分析限定为预测敏感性

- 日期：2026-10-22（Asia/Shanghai）
- 状态：依据总任务书M6条件闸门作出的版本范围决定
- 证据：[正式test](../../research/forecast-results-v1.md)、[局限](../../research/limitations.md)

## 背景

M6明确要求“有价值才做”，允许数据不足时以ADR降级为纯数值研究。
当前NCA在5条代理test序列的H24 IoU约0.460，优于两个朴素基线，但边界指标未全面领先，存在提前闭合失败。
小更新惩罚没有明显收益；数据没有受控场、药物、基因或环境干预，网络输入没有可验证的生物控制参数。
把隐状态画笔或任意力场暴露给优化器会产生未经数据约束的响应，现有预测证据不能验证这些响应。

## 备选

1. 立即增加画笔和预算优化：界面易演示，但目标函数可下降并不证明模型在干预下可信。
2. 加入独立合成控制研究：可计算，但研究域和实验重点会显著扩张，必须另定义可识别动力学与对照。
3. 本版保留观察条件下的预测与数值敏感性，明确不实现控制优化。

## 决定与后果

选择3。已完成的共同origin、共同QC、L2/4/8输入长度实验作为数值可靠性证据，报告全部方法与负结果；
它不是对扰动、干预或不确定性的完整验证。M6本版按条件降级，不声称完成预算约束控制、随机控制baseline、A/B干预快照或因果可靠性。
工作台不显示无效“智能干预”按钮，不以视觉演示推动未经验证的控制结论。

后续若扩展，需要独立协议：定义可识别的抽象控制输入与范围、训练支持、预算、目标、随机/梯度基线、
外推检测与固定保留测试；所有输出标IN_SILICO且明确没有现实治疗含义。
改变主数据域、监督目标或引入真实生物干预解释时按工作协议先报告负责人决定。

本决定不放弃NCA，不改变形态预测目标，也不把当前负结果改写成成功的控制研究。
