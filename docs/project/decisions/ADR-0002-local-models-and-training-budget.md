# ADR-0002 · 局部预测模型、共同输入与训练预算

- 日期：2026-10-21
- 状态：接受；正式训练之前冻结，不以test结果修改。
- 前提：[ADR-0001](ADR-0001-observed-domain-target-and-split.md)与可复现M2基线。当前神经模型未训练、未评估。

## 问题与备选

验证局部共享规则是否能进行真实轮廓条件下的长期形态预测，而非复现emoji成长。既有创面视频预测和NCA动力学不构成本项目创新声明。比较受条件化方式、训练跨度和计算预算影响；须固定共同输入与最小改动。

候选包括整帧视频预测、完整灰度分割+预测、派生形态预测。维持ADR-0001的派生形态任务，不把分割/显微纹理生成混入当前研究。

## 模型与共同输入

所有可学习模型接收相同L帧历史SDF。用末帧形态与历史SDF逐像素最小二乘时间斜率作为共同两通道条件；时间自变量只用历史帧索引，无未来标签。L默认4，另评估L=2/8的输入长度敏感性，不称新增数据。

- **Vanilla NCA**：16通道状态，显式保留末帧SDF与历史斜率，其余潜在通道由小卷积编码。每步通过固定identity、Sobel-x/y、Laplacian深度分组局部感知及共享1×1网络计算残差；同步更新、步长0.1，隐藏状态裁剪±4，输出SDF裁剪±1。边缘采用复制边界并明确记录。默认不引入随机更新或emoji式存活门控。
- **ConvGRU对照**：同样两通道条件初始化16通道隐藏状态，3×3局部门控，递归预测SDF残差，步长0.1与同样输出范围。它是summary-conditioned ConvGRU，不冒称原论文网络复现。
- **最小改进**：与Vanilla NCA相同源码和参数，仅训练损失增加平均状态更新平方惩罚，权重固定0.001。其含义是数值正则，不是实测能量；0权重即消融，不同时叠加其他新约束。

各模型参数量、实际用时和峰值内存均记录；共同优化步数不代表实际FLOPs严格相同，不以此声称完全等计算预算或纯粹局部规则的因果收益。

## 训练与选择

- 主实验3 seeds：17、29、43；每种可学习方法最多600个优化步，batch=8，Adam学习率0.002，梯度范数上限1，fp32。
- 每步均匀采样训练源序列，再在该序列合法L4/H12窗口中采样起点；各方法使用同seed确定的同一采样/增强流。随机90度旋转与翻转对历史/未来共同应用，仅训练使用。
- 自由滚动训练H=12，不用未来真值更新状态。共同损失为多步加权SDF MSE，加0.1软区域Dice损失；SDF像素权重`1+4*exp(-4*abs(target_sdf))`，软区域取`sigmoid(5*prediction)`。
- 每100步在固定validation共同H24窗口评价，以相同多步监督损失选择best checkpoint；step 600为统一预算上限，不因test差异延长某模型。保存last与best、优化器、采样/torch RNG和完整元信息以恢复。
- 训练与数值fixture先验证；真实正式run仅在实现提交、push与SHA核对后从干净相关源码启动。异常NaN/Inf明确失败，不伪造缺失指标。

## 评价与局限

沿用M2的统一最长H24合法窗口和序列等权指标，报告H4/12/24，3 seeds与每序列结果。test保留至实现与配置冻结后统一评估。边界消失按已定义失败惩罚，不只报告均值IoU。

NCA的0与0.001惩罚是主消融；可追加仅训练H1的单seed有限消融，必须标明预算和seed局限。没有实证改进也如实报告。基础模型不具备真实干预因果含义，虚拟控制仍需后续独立闸门。

## 运行环境

PyTorch以可选CPU/CUDA extras锁定，基础审计与浏览无需框架。CPU与CUDA选择互斥，GPU不可用时明确退回CPU；本机环境不依赖同级项目。选择依据为[PyTorch官方安装说明](https://pytorch.org/get-started/locally/)和[uv的PyTorch集成](https://docs.astral.sh/uv/guides/integration/pytorch/)，实际版本和设备能力以安装后运行验证为准。
