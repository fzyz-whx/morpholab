# 开发路线图

来源：总任务书 v0.2。阶段按依赖推进，不承诺固定工期，不用 UI 完成度代替科研验收。

| 阶段 | 目标 | 验收依据 | 状态 |
|---|---|---|---|
| M-1 | 从空目录建立公开仓库与工作协议 | 首提交即时 push、远端 SHA、README、最小 CI | 已完成 |
| M0 | 数据与相关工作审计 | 真实压缩包、至少两条六时间点序列、QA、hash、许可、标签与拆分 ADR | 已通过，公开限制保留 |
| M1 | 设计系统与真实数据浏览 | 实际浏览器交互、1440×900 / 1280×720 审查、组件及 E2E 证据 | 已通过，三项远端CI成功 |
| M2 | 统一数据管线与经典基线 | 实验级清单、无泄漏、Persistence / Classical、公平指标与失败案例 | 正式validation完成，报告审查中 |
| M3 | NCA 与时序网络 | 自主核心实现、真实训练、检查点、同拆分对照、最小假设改进 | 协议冻结、数值fixture通过；真实未训练 |
| M4 | 正式对照与研究结论 | 固定协议、多 seed / horizon、消融、局限与可复算报告 | 未开始 |
| M5 | 后端与工作台闭环 | 持久作业、真实预测 API、结果浏览、完整 E2E、新克隆复现 | 未开始 |
| M6 | 可选模型内控制 | 以前序可信预测为前提；预算约束与随机基线；无现实因果声明 | 未开始 |
| M7 | 发布与复现验收 | 文档、真实图表、许可证、干净克隆、CI / E2E、范围相符的 Release | 未开始 |

每个独立工作单元按检查 → 测试 → commit → 立即 push → 远端 SHA 核对推进。阻断先处理，不进入下一提交。

重大决策放入递增 ADR，包含日期、背景、候选、选择理由、后果与证据。主数据域或监督任务变更先交负责人决策。

本轮恢复已获授权自主推进完整项目；每阶段仍遵守闸门，不一次生成全项目。尚未通过验收的模块不标为完成。
