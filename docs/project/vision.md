# 项目愿景

MorphoLab 将真实生物显微时序、可复现预测实验和可交互科研工作台连接起来。主要用户是本科 AI 研究者、生物计算教师及需要检查代码和证据的公开仓库读者。

核心问题是：有限的早期观测中，局部共享神经更新规则能否预测后续创面形态，并保持长期稳定？是否优于简单方法必须靠实验回答。NCA、视频预测和外部条件响应已有研究，本项目需明确相邻工作和自身假设。

初始研究对象为果蝇胚胎体内激光创面闭合，数据以 Zenodo 7660424 为第一审计目标。数据域、监督信号、官方划分和指标由 M0 证据及 ADR 确定。未知信息不从示例或直觉补造。

目标使用流程：查看来源与质量 → 浏览真实观测和标注 → 选择观测窗口 → 运行已训练预测模型 → 对照后续真值与误差 → 追踪实验配置与失败案例。模型内虚拟控制须在可靠预测后单独建设。

不做医疗诊断、真实治疗推断、LLM 聊天、商业云服务、账号系统或 3D。早期不做宣传视频和复杂演示。研究证据优先，界面须认真设计，二者分别验收。

源码默认 MIT，第三方资源单独核验条款。项目本机路径、凭据和未获发布权的资源不进入公开仓库。
